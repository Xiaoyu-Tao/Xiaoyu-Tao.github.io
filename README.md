## Local Development

Open `index.html` in a browser, or serve the folder locally:

```bash
# Python
python -m http.server 8000

# Node (npx)
npx serve .
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — Main page
- `styles.css` — Styles
- `scripts.js` — Dynamic content (publications, projects)
- `publications.json` / `projects.json` — Data
- `images/` — Profile, favicon, publication/project figures
